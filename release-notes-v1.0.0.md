# L33T R3PL4Y v1.0.0

**Record. Edit. Replay.**

The first formal release of L33T R3PL4Y, a Windows application for
recording, editing, and replaying mouse and keyboard input macros.

## Highlights

- Dedicated Playback & Editing and Recording workspaces
- Mouse and keyboard input recording
- Recording countdown, pause, resume, stop, and cancellation
- Event list and timeline views
- Event editing, filtering, search, undo, and redo
- Adjustable playback speed
- Finite, custom, and infinite playback loops
- Dry Run mode for safe testing
- Confirmation before real playback
- Align Start cursor positioning
- Display compatibility information
- System tray integration
- Multiple themes and accent colors

## Active Workspace Hotkeys

- **F9** — Start or stop
- **F10** — Pause or resume
- **Ctrl+Shift+Escape** — Emergency Stop

F9 and F10 control whichever workspace is currently open.
